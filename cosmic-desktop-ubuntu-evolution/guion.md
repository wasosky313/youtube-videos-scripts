Se llama **Cosmic Desktop**.

Si eres usuario de Ubuntu y siempre sentiste que algo no cuadraba, o si simplemente quieres un entorno de escritorio que sea moderno, fluido y que realmente entienda cómo trabajas — este vídeo es para ti.

Cosmic no es una distro nueva. Es un derivado de Ubuntu que la gente de System76 (sí, los del Lemur Pro) está desarrollando, y está creciendo exponencialmente en la comunidad. ¿Por qué? Porque trae cosas que Ubuntu nunca tuvo como default."

---

## ¿QUÉ ES COSMIC? (0:45 – 2:30)

**[Print: desktop de Cosmic Desktop]**

"Cosmic Desktop es un entorno de escritorio moderno construido sobre Rust — el mismo lenguaje que usa Firefox hoy en día.

Está basado en Ubuntu, así que si vienes de Ubuntu, no es un salto de fe. Es más como una actualización que alguien debería haber hecho hace años.

**[Mostrar el panel y el layout]**

Mirá esto: en Cosmic, cuando abrís una ventana, podés hacerla snap en los lados de la pantalla. Pero no es como ese sistema básico que tiene Windows o el default de Ubuntu — es un tiling window manager integrado de verdad. Las ventanas se acomodan automáticamente, se dividen, se adaptan. Sin configuración complicada.

**[Demo: abrir dos ventanas y mostrar cómo se snappean]**

Esto es lo que durante años solo veías en window managers como Hyprland o i3 — pero aquí está integrado de forma que cualquiera lo entiende. No necesitas aprender comandos raros. Solo arrastrás una ventana al lado y... boom. Se adapta.

Eso es lo que me atrae de Cosmic. Toma ideas de sistemas simples como macOS o Windows, las mejora, y las empaqueta de una forma que tiene sentido."

---

## EL PROBLEMA DE UBUNTU (2:30 – 4:00)

**[Cámara en la cara]**

"Mirá, Ubuntu estuvo durante años siendo la distro de referencia. Canonical hizo un trabajo increíble democratizando Linux.

Pero en los últimos años pasó algo: GNOME evolucionó para un lado, Ubuntu evolucionó para otro. Y el resultado fue un escritorio que se sentía... no sé, un poquito bloated. Mucho de todo.

Canonical intentó varias cosas — Unity, después volvió a GNOME, después intentó Snap como base para todo... y la comunidad siempre terminó peleando con algo.

**[Print: configuración de Ubuntu]**

La experiencia por defecto simplemente no era tan pulida como debería haber sido.

Y mientras eso pasaba, la gente que venía de Ubuntu estaba yendo a dos lugares:
- Para un lado: Arch, Fedora, distros más técnicas
- Para el otro lado: macOS, porque 'al menos funciona'

Cosmic llega para resolver esto. Es decir: 'Vos querés Ubuntu, pero querés que funcione bien'. Simple."

**[Gravación de pantalla en tiempo real]**

"1. **Snap/Tiling Automático**

**[Demo: arrastrar ventana al lado y que se adapte]**

Como te mostré antes, esto es el corazón de Cosmic. No es un gimmick — cambió cómo trabajo en realidad. Cuando tengo dos documentos o dos ventanas abiertas, se adaptan solas. No hay que estar jugando con tamaños.

2. **Performance**

**[Abrir varias aplicaciones, mostrar que no lag]**

Cosmic está escrito en Rust, y se nota. El escritorio es fluido. Las animaciones son suaves. No hay ese lag que a veces tenía GNOME con muchas ventanas.

3. **Diseño coherente**

**[Mostrar el tema, colores, iconos]**

Todo está diseñado pensando en los usuarios, no en los desarrolladores. Los iconos tienen sentido, el tema es consistente, los colores funcionan juntos.

4. **Accesibilidad para principiantes**

**[Mostrar el menú, las preferencias]**

Si venís de Ubuntu, no hay curva de aprendizaje. Si venís de Windows o Mac, tampoco. Está hecho para que cualquiera lo entienda.

5. **Comunidad creciente**

**[Mostrar comentarios, discusiones en Reddit o Matrix]**

Esto es importante. Hace un año, Cosmic era un proyecto experimental. Hoy, la comunidad está activa, reportando bugs, sugiriendo features. Eso significa que va en serio."
